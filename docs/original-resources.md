# 日文原改版解包成果与定位指南

对象是 **HaruDX v05_09 日文原改版**，不是零售日文原作或 Titans。只接受 4 MiB 无头 ROM，SHA-256 为 `5cea22b5995e91e7e19c9ff73a2036f1929e5f162ea56d0819628728ec3d50d0`。

## 当前公开的成果

| 文件 | 分母与范围 |
|---|---|
| `original/graphics-index.json` | 文件偏移 `160000` 起 330 个三字节指针槽，329 项非空；记录压缩源、真实终点、长度、解压长度、哈希及历史缓冲依赖 |
| `original/indexed-text-seeds.tsv` | 既有工程已识别的 8728 个目录/索引/分支路径；不含正文或编码字节 |
| `original/text-index.json` | 8725 项可解析到有界 FF token 流，3 项 unresolved；保存地址、长度、哈希和控制码数量 |
| `original/summary.json` | 精确输入身份、分母、解析结果与限制 |
| `tools/inspect_original.py` | 从自备 ROM 重新生成以上 JSON；可选本地提取压缩和解压数据、编码正文 |

目录记录来自既有可识别文本集合，不是重新证明所有原生表长，也不是每条都已由游戏实际读取的声明。三个旧目录路径在本工具的原生选择器解析中无法成立，会保留原因；它们可能是历史目录别名或未支持的复合控制，**不能仅据此判为游戏错误**。

文本扫描将 FE/FB 的参数作为整体 token，不能在参数里的 FF 提前结束。F0..F5 为双字节；F6/F7/FF 和 F8..FE 的长度按本作已知语法处理。扫描到的 FF 只证明该语法范围内的长度，不证明剧情可达性、显示含义或所有跳转消费者。

## 压缩流边界

图像使用本作 `80:F93D` 对应的位标记／literal／short／long 回溯格式。`native_lz.py` 可返回实际消耗源长度和输出；终止由 long 特殊命令识别。连续 00 可属于有效压缩数据，不能当作空闲区，也不能用搜索三个 00 代替解码。

索引里的解压哈希明确采用前置 8192 字节全零条件。如果流会引用输出之前的历史，`requires_preexisting_history` 为 true。该条件下生成的 `.zero-history.bin` 不保证等于每次运行现场的图像；分析时必须跟踪调用方准备的实际缓冲区。

解压终点也不证明后面的区域没有其他数据。任何资源搬迁或扩写都要核对引用、使用者与分配账。

## 本地提取和使用

```powershell
python tools/inspect_original.py 'D:\ROM\HaruDX_v05_09.smc' --output local/original-index
python tools/inspect_original.py 'D:\ROM\HaruDX_v05_09.smc' --output local/unpacked --extract
```

默认只生成 JSON，方便和仓库结果比较。`--extract` 另写 `graphics/`、`encoded-text/` 下的 `.bin`，它们属于用户自备 ROM 的本地提取成果，已被 `.gitignore` 排除。

当前工具不生成可直接重插全游戏的工程：没有全部地图/动画指令反汇编、完整脚本 VM 编辑器或通用重排分配器。原编码文本需结合实际字库/decoder 才能解码为人类可读台词；这里未发布第三方字库或完整原文。

## 怎样区分原改版 bug 与汉化／功能补丁问题

1. 固定日文原改版、对应标准汉化和 X 版的精确身份，分别冷启动同一兼容普通存档；先确认场景可达。
2. 跟踪实际入口、图像解压源/终止/输出长度/目标缓冲，以及临时索引和持久队伍记录，抓首次异常写入。
3. 同一输入路径的日文版也异常，才有原改版归因证据。只有汉化异常则检查文本/资源覆盖与原生参数；只有按 X 跳过异常则检查跳过后的控制流。
4. 用同一路线复测修复，再检查保存、冷读档和后续交互。

已有历史发现中，改造列表被破坏、战斗姓名/头像参数混乱等多个问题归因于汉化资源覆盖或参数损坏，**不能合并标为上游原改版 bug**。布里基大王在空域出击受限，在日文原改版与当时汉化版表现一致，装备飞行部件后可出击，属于已复现的地形限制；用户第31话自然进度的全部情况没有复现，不应因此直接更改机体玩法。

本仓库目前没有“已确认且未修复的原改版 bug 全表”。欢迎提交具名场景和首次异常证据；通用索引及提取工具用于协助定位，不代表未知问题已经排查完毕。
